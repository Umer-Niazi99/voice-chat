Thinkers Alliance School Bhakkar - Voice Portal
================================================
1. Install Node.js 18 or newer (nodejs.org)
2. Open PowerShell in this folder, then run:
      npm install
      npm start
3. Open http://localhost:3000

Notes
- API keys are in the .env file (never share or upload it).
- Microphone works on localhost or HTTPS only. On a phone, deploy to an HTTPS host.
- Logo: drop your school logo as public/logo.png (it is picked up automatically).
- Teachers, subjects, fees, activities: edit knowledge.js
